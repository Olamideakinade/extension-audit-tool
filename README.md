> 🚀 **v1.1.0 Release:** Advanced security posture analysis, live filtering, and report exports for local MCP servers, extensions, and plugins.

## Features

- **Deep Manifest Inspection**: Analyze `mcpServers` and extension configurations for supply chain vulnerabilities.
- **Risk Scoring**: Automated high, medium, and low risk detection based on execution parameters and publisher verification.
- **Report Export**: Export audit results in JSON or CSV format for compliance tracking.
- **Real-Time Filtering**: Instant search and severity classification filters.

## Getting Started

Clone the repository and open `index.html` in any modern web browser or serve via static file server.
