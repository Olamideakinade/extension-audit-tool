# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v1.1.0] - 2025-02-18

### Added
- Export capabilities for security reports in JSON and CSV formats.
- Real-time search filter and severity toggle buttons.
- Comprehensive CSS polish for modern dark mode aesthetics and high-contrast badges.

### Changed
- Updated `app.js` with complete audit evaluation logic and reactive DOM rendering.
- Enhanced UI layout in `index.html` and expanded stylesheet in `style.css`.

### Fixed
- Handled edge cases for malformed JSON manifests with graceful error boundaries.
