# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v1.2.0] - 2025-02-24

### Added
- Executive compliance scoring model evaluating assets against hardening criteria.
- Vulnerability distribution analytics and risk categorization graphs.
- HTML executive summary export alongside existing JSON and CSV options.
- Robust input validation and error boundaries for corrupted manifests.
- Keyboard shortcut support for quick filtering and report generation.

### Changed
- Upgraded `app.js` with modular audit runners and reactive state management.
- Refined `style.css` with compliance badge indicators and high-density analytics widgets.

### Fixed
- Handled edge cases with malformed JSON manifests during drag-and-drop ingestion.
