# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v1.3.0] - 2025-02-27

### Added
- Batch manifest file queueing and comparative security analysis.
- Real-time search filter for auditing specific binaries, args, and endpoints.
- Local storage persistence for historical audit comparisons and session restore.
- Enhanced pattern matching for remote script execution hazards.

### Changed
- Upgraded compliance scoring engine to weigh remote HTTP execution vectors more severely.
- Refactored UI layout for high-density monitoring dashboards.
